# 👋 Hi, I'm Jaret

I'm a **Project Engineer** with a background in software development and machine vision. I enjoy building practical solutions that bridge the gap between software and real-world systems.

I earned my **Bachelor of Science in Computer Science from the University of Kansas**.

> Some public projects are simplified versions of applications originally developed for professional use. Other repositories are personal projects and independent work.

## 🚀 Featured Projects

### [PropWise](https://github.com/jaretpr/PropWise)

A Chrome extension for researching NFL, MLB, and NBA player props using live sports data, player statistics, projections, and model-based analysis.

### [EFiling-Automation](https://github.com/jaretpr/EFiling-Automation)

A Python application that automates e-filing workflows, including browser interaction, document uploads, form submission, and Excel tracking.

### [User-Account-Creator](https://github.com/jaretpr/User-Account-Creator)

A PowerShell tool that automates Active Directory account creation, network folder setup, user attributes, and KnowBe4 enrollment.
